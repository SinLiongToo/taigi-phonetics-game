# 台語子母音歡樂派對：打地鼠 ＆ 3D 魔術方塊

專為兒童設計、100% 全新原創開發的台語羅馬字（子音・母音）互動學習遊戲。

## 遊戲啟動方式

直接以瀏覽器開啟 [index.html](file:///c:/Users/tu-hs/OneDrive/文件/2022_0308_MASA/2022-0708/Projects_antigravity/TG_GAME_字母音/index.html) 即可遊玩（零外部框架依賴、單一檔案完整運作）。

## 設計特色

1. **常駐頂部導覽列（隨時一鍵回主頁）**
   - 頂部常駐 HTML 導覽列提供醒目的 **`🏠 回主頁`**、**`🚩 選關卡`**、**`📖 子母音圖鑑`** 按鈕。
   - 遊戲進行中、課前教學卡、過關結算彈窗皆設有 **`🏠 主頁`** 按鈕（亦可按 `Esc` 鍵），任何時刻都能立即返回主頁，絕不卡關。

2. **零亂碼字型與乾淨編碼架構**
   - 全面採用標準 UTF-8 NFC 正規化編碼，移除所有在 Windows 瀏覽器／Canvas 容易產生方框亂碼的複合變體選擇符（`U+FE0F`、鍵帽組合碼 `U+20E3` 等）。
   - 優先載入支援完整台羅聲調符號（含第 8 調直立線 `U+030D` 與白話字 `o͘` `U+0358`）的 `Charis SIL`、`Calibri`、`Segoe UI` 字型序列，確保台語羅馬字與漢字清晰美觀。

3. **三大互動玩法（可隨時於頂部一鍵切換）**
   - **🔨 歡樂打地鼠（Kòng Tē-tshí）**：九宮格草地洞穴，看頂端題目缺哪個子音或母音，用木槌敲擊舉著正確字母木牌的小動物（支援滑鼠、觸控與數字鍵 `1`～`9`）。
   - **🧊 3D 魔術方塊（3D Môo-su̍t Hong-khuài）**：立體 3×3×3 彩色魔術方塊，支援 360° 拖曳旋轉視角與六個行列轉層按鈕（`Q/W/E/A/S/D`），找出並點選正確的子母音方塊格（轉到正中央黃金框可獲雙倍加分）。
   - **🧩 子母音拼字魔方（Phing-jī Hong-khuài）**：左邊為「頭前音（子音 3D 方塊）」、右邊為「後壁音（母音韻母 3D 方塊）」，轉動左右兩顆魔方拼出完整台語單字後按下「魔方合體拼音」！

4. **10 個全新原創台語子母音學習單元**
   - **Unit 1**：雙唇音小隊（`p, ph, b, m`）
   - **Unit 2**：舌尖音小隊（`t, th, n, l`）
   - **Unit 3**：舌根與喉音（`k, kh, g, ng, h`）
   - **Unit 4**：齒音小隊（`ts, tsh, s, j`）
   - **Unit 5**：六大基礎母音（`a, i, u, e, o, oo`）
   - **Unit 6**：雙母音滑音篇（一）（`ai, au, ia, iu, io`）
   - **Unit 7**：雙母音與三母音（二）（`ua, ue, ui, iau, uai`）
   - **Unit 8**：鼻化母音篇（`ann, inn, enn, iann, uann`）
   - **Unit 9**：入聲短促尾音（`-p, -t, -k, -h`）
   - **Unit 10**：大魔王總挑戰（全體子母音綜合隨機考驗）
